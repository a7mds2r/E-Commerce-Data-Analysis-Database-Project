A complete end-to-end data analysis project for an e-commerce platform. This project covers the full data pipeline — from raw data ingestion, through cleaning and transformation, to loading into a MySQL relational database and generating insightful visual dashboards using Python.

### `data/`

Contains all project datasets, organized into two subdirectories separating raw from processed data.

#### `data/O_data/` — Original (Raw) Data

The **original, unmodified CSV files** as initially collected. These files contain raw data including potential duplicates, missing values, outliers, and inconsistent formatting (e.g., ISO 8601 timestamps with `T` separators).

| File | Records | Size | Columns | Description |
|------|---------|------|---------|-------------|
| `users.csv` | 10,000 | 750 KB | `user_id`, `name`, `email`, `gender`, `city`, `signup_date` | Registered user profiles with demographics and signup dates. Gender values include Male, Female, and Other. |
| `products.csv` | 2,000 | 98 KB | `product_id`, `product_name`, `category`, `brand`, `price`, `rating` | Product catalog with pricing, brand, category classification, and product ratings. |
| `orders.csv` | 20,000 | 1.2 MB | `order_id`, `user_id`, `order_date`, `order_status`, `total_amount` | Order transactions with statuses (e.g., processing, completed) and total amounts in USD. |
| `order_items.csv` | 43,525 | 2.2 MB | `order_item_id`, `order_id`, `product_id`, `user_id`, `quantity`, `item_price`, `item_total` | Individual line items within each order, linking orders to specific products with quantities and prices. |
| `reviews.csv` | 15,000 | 1.4 MB | `review_id`, `order_id`, `product_id`, `user_id`, `rating`, `review_text`, `review_date` | Customer reviews with numeric ratings (1–5) and text feedback tied to specific orders and products. |
| `events.csv` | 80,000 | 4.7 MB | `event_id`, `user_id`, `product_id`, `event_type`, `event_timestamp` | User behavior/interaction events (view, cart, purchase, etc.) for tracking the customer journey. |

#### `data/clean_data/` — Cleaned & Processed Data

The **cleaned and transformed versions** of the raw data, produced by the main analysis notebook (`E-comerce.ipynb`). The cleaning pipeline applied the following transformations:

- **Date/time formatting**: Converted ISO 8601 timestamps (e.g., `2025-09-09T14:52:37`) to MySQL-compatible datetime format (e.g., `2025-09-09 14:52:37`).
- **Duplicate removal**: All duplicate rows were dropped across all datasets.
- **Missing value handling**: Rows with null values were removed.
- **Outlier removal**: Numeric columns were cleaned using the **IQR (Interquartile Range) method** — values below Q1 − 1.5×IQR or above Q3 + 1.5×IQR were removed.

| File | Records | Size | Notes |
|------|---------|------|-------|
| `users.csv` | 10,000 | 760 KB | No records removed (no duplicates/nulls/outliers detected). |
| `products.csv` | 1,763 | 88 KB | **237 records removed** — likely products with outlier pricing or ratings. |
| `orders.csv` | 20,000 | 1.2 MB | No records removed. |
| `order_items.csv` | 38,417 | 1.9 MB | **5,108 records removed** — items with outlier quantities or prices filtered out. |
| `reviews.csv` | 15,000 | 1.4 MB | No records removed. |
| `events.csv` | 80,000 | 4.8 MB | No records removed. |

### `database/`

Contains the **MySQL database schema** and design artifacts for the relational data warehouse.

#### `E-commerce_db.sql`

A DDL (Data Definition Language) SQL script that creates the `E_COMMERCE_DB` database with a **star schema** design consisting of **2 dimension tables** and **4 fact tables**:

**Dimension Tables (Lookups):**

| Table | Primary Key | Description |
|-------|-------------|-------------|
| `dim_users` | `user_id` (VARCHAR) | User dimension — stores user profiles (name, email, gender, city, signup date). |
| `dim_products` | `product_id` (VARCHAR) | Product dimension — stores product catalog (name, category, brand, price, rating). |

**Fact Tables (Transactional Data):**

| Table | Primary Key | Foreign Keys | Description |
|-------|-------------|--------------|-------------|
| `fact_order` | `order_id` | `user_id` → `dim_users` | Core order facts — order date, status, and total amount. |
| `fact_order_items` | `order_item_id` | `order_id` → `fact_order`, `product_id` → `dim_products`, `user_id` → `dim_users` | Order line items — links orders to products with quantity and pricing details. |
| `fact_reviews` | `review_id` | `order_id` → `fact_order`, `product_id` → `dim_products`, `user_id` → `dim_users` | Customer reviews — rating, review text, and review date. |
| `fact_events` | `event_id` | `user_id` → `dim_users`, `product_id` → `dim_products` | User behavior events — event type and timestamp for tracking interactions. |

#### `Taabels.mwb`

A **MySQL Workbench** model file (`.mwb`) containing the visual **Entity-Relationship (ER) diagram** for the database schema. Open this file in MySQL Workbench to view and edit the table relationships graphically.

### `notebook/`

Contains **2 Jupyter notebooks** that implement the data processing pipeline and analysis.

#### `E-comerce.ipynb` — Main Analysis Notebook

The primary notebook (~479 KB) that performs the complete data analysis workflow:

1. **Data Loading**: Reads all 6 raw CSV files from `data/O_data/` into Pandas DataFrames.
2. **Exploratory Data Analysis (EDA)**: Inspects data types, shapes, and basic statistics using `.info()` and `.head()`.
3. **Data Cleaning**:
   - Fixes wrong data types and invalid dates using `pd.to_datetime()` with `errors="coerce"`.
   - Removes duplicate rows with `drop_duplicates()`.
   - Drops rows with missing values using `dropna()`.
   - Detects and removes outliers using the IQR method.
4. **Data Export**: Saves all cleaned DataFrames to `data/clean_data/` as CSV files.
5. **Dashboard / Visualization**: Connects to the MySQL database via SQLAlchemy and executes SQL queries to generate 6 analytical charts using Matplotlib and Seaborn:
   - Revenue Trend Over Time (monthly)
   - Top 10 Selling Products (by quantity)
   - Revenue by Category
   - Top Customers (by total spend)
   - Event Type Distribution
   - Average Product Ratings

**Libraries used**: `pandas`, `matplotlib`, `seaborn`, `sqlalchemy`, `pymysql`, `os`

#### `sql data.ipynb` — Database Loader Notebook

A utility notebook (~7.5 KB) dedicated to **loading the cleaned CSV data into MySQL**. It:

1. Connects to the local MySQL server using `pymysql`.
2. Reads each cleaned CSV file from `data/clean_data/`.
3. Dynamically constructs `INSERT INTO` statements based on column headers.
4. Uses `cursor.executemany()` for batch insertion.
5. Loads data into the database tables in the correct order respecting foreign key constraints:
   - **Dimension tables first**: `dim_users` (10,000 rows), `dim_products` (1,763 rows)
   - **Fact tables second**: `fact_order` (20,000 rows), `fact_order_items` (38,417 rows), `fact_reviews` (15,000 rows), `fact_events` (80,000 rows)

## 🔄 Data Pipeline Overview

```
┌──────────────┐     ┌──────────────────┐     ┌───────────────┐     ┌──────────────┐
│  Raw CSVs    │────▶│  EDA & Cleaning  │────▶│  Clean CSVs   │────▶│  MySQL DB    │
│  (O_data/)   │     │  (E-comerce.ipynb)│     │  (clean_data/)│     │  (star schema)│
└──────────────┘     └──────────────────┘     └───────────────┘     └──────┬───────┘
                                                                           │
                                                                           ▼
                                                                   ┌──────────────┐
                                                                   │  Dashboard   │
                                                                   │  (charts/)   │
                                                                   └──────────────┘
```

1. **Raw data** is stored in `data/O_data/`.
2. **`E-comerce.ipynb`** cleans and transforms the data → saves to `data/clean_data/`.
3. **`E-commerce_db.sql`** creates the database schema in MySQL.
4. **`sql data.ipynb`** loads the cleaned CSVs into MySQL tables.
5. **`E-comerce.ipynb`** queries the MySQL database and generates charts → saved to `charts/`.

## 🚀 Getting Started

### Prerequisites

- Python 3.11+
- MySQL Server (local or remote)
- Jupyter Notebook or JupyterLab

### Setup

1. **Install Python dependencies:**
   ```bash
   pip install pandas matplotlib seaborn sqlalchemy pymysql
   ```

2. **Create the database schema:**
   ```bash
   mysql -u root -p < database/E-commerce_db.sql
   ```

3. **Run the main notebook** (`notebook/E-comerce.ipynb`) to:
   - Clean the raw data and export to `data/clean_data/`.
   - Generate the dashboard charts.

4. **Load data into MySQL** by running `notebook/sql data.ipynb`.

> ⚠️ **Note**: Update the MySQL connection credentials (`host`, `user`, `password`) in both notebooks to match your local MySQL configuration.
